# Path to Peak

A personal training tracker: define your own metrics (vertical jump, deadlift,
sprint time, standing reach in feet & inches — whatever), log values over
time, and see history, stats, and a trend graph per metric. Set an optional
goal (with a target date) and the app shows your progress, whether you're
ahead or behind pace, and a projected finish date based on your current
trend. All data is stored on your phone only (localStorage) — nothing leaves
the device.

This is a Capacitor project: a real Android app wrapping a small web app.
It has no backend and needs no internet connection once installed.

## Getting the APK onto your phone (no Android Studio needed)

You need a free GitHub account. GitHub's servers have the Android build
tools already installed, so they'll compile the APK for you — you just
have to upload this project.

**1. Create a repository**
Go to github.com → **New repository** → name it (e.g. `path-to-peak`) →
leave it empty (don't add a README/gitignore) → **Create repository**.

**2. Upload this project**
Easiest: open the repo page → **Add file → Upload files** → drag the
*entire contents* of this folder (including the hidden `.github` folder —
make sure your file browser is set to show hidden files, since that's
where the build robot lives) into the browser window → **Commit changes**.

If drag-and-drop misbehaves with the nested folders, install
[GitHub Desktop](https://desktop.github.com/) instead, add this folder as
a local repository, and hit **Publish repository** — it handles the whole
folder structure correctly every time.

**3. Let it build**
Click the **Actions** tab on your repo. A workflow called "Build APK" runs
automatically after your upload — takes about 2–3 minutes. A green check
means it worked.

**4. Download the APK**
Click into the finished run → scroll to **Artifacts** → download
`path-to-peak-apk` (a zip with `app-debug.apk` inside). You can do this
straight from your phone's browser if you're logged into GitHub there.

**5. Install it**
Unzip, tap `app-debug.apk`. Android will warn about installing from an
unknown source — that's expected for a sideloaded app, not a bug. Allow it
for this file and install.

## Making a change later

Edit files in `www/` (that's the whole app — `index.html`, `style.css`,
`app.js`), commit and push. The Actions workflow rebuilds automatically
and a fresh APK shows up in Artifacts.

## Editing or deleting a metric

Open the metric, tap the pencil (✎) icon top-right. From there you can
rename it, change its unit or direction, add/edit/remove its goal, or
delete the metric entirely (which also deletes its history).

## Backing up your data

There's no cloud sync. Use the `⋯` menu on the home screen → **Copy my
data** to grab a text snapshot of everything (paste it into a notes app or
email it to yourself). **Restore from text** puts it back, including onto
a phone after a reinstall.

## Project layout

```
www/               the actual app (HTML/CSS/JS)
android/           native Android wrapper (generated by Capacitor)
.github/workflows/ the robot that builds your APK on GitHub's servers
icon-*.svg         source art for the app icon, in case you want to tweak it
```
